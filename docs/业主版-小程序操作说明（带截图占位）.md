### 1. 本文档适合介绍哪些内容

本文档默认按普通业主视角编写，主要覆盖：

- 登录 / 注册

- 社区任务
- 闲置商品
- 社区活动
- 我的页面
- 钱包 / 提现
- 消息 / 收藏 / 浏览记录

本文档不包含管理员后台操作说明。

## 二、进入小程序

### 1. 打开后先看到欢迎页

业主首次进入小程序，会先看到欢迎页。页面会展示：

- 小程序主视觉
- 特定人群使用说明
- `登录 / 注册` 按钮

这一步主要是告诉业主：这是面向合作小区住户使用的小程序，不是对社会开放的匿名平台。

【截图01：欢迎页】

建议截图内容：

- 页面主视觉
- `登录 / 注册`
- `使用说明（特定人群）`

可配说明文字：

> 第一次进入小程序时，会先看到欢迎页。这里会说明本小程序仅面向合作小区住户开放，并提供登录 / 注册入口。

## 三、登录 / 注册与实名验证

### 1. 先选择所属小区，再去注册

如果是第一次使用，点击 `登录 / 注册` 后，会先选择所属小区，再进入实名注册流程。

【截图02：选择所属小区弹窗】

建议截图内容：

- `选择所属小区`
- `请选择小区`
- `确定并去注册`

可配说明文字：

> 新用户首次进入时，需要先选择所属小区，再进入注册流程。这样可以减少非本小区用户误入。

### 2. 按页面提示完成实名信息填写

实名注册页会引导用户完成以下步骤：

- 选择头像
- 填写昵称
- 上传身份证正反面
- 选择身份证有效期
- 点击 `获取` 授权手机号
- 选择所属小区
- 选择楼栋和门号
- 点击 `获取定位`
- 勾选 `用户协议` 和 `隐私政策`
- 点击 `继续`

【截图03：实名注册页上半部分】

建议截图内容：

- `验证业主身份`
- 头像 / 昵称
- 身份证上传区域
- 手机号获取按钮

【截图04：实名注册页下半部分】

建议截图内容：

- 所属小区
- 楼栋 / 门号
- `获取定位`
- 协议勾选
- `继续`

可配说明文字：

> 为了保障社区安全，注册时需要完成实名、小区信息和定位校验。只有通过验证后，才能使用交易、活动、钱包等核心功能。

### 3. 完成实名后，即可进入小程序主页面

实名成功后，用户会进入小程序主页面，可以开始查看任务、商品、活动等内容。

【截图05：登录后的主页面或任务页】

建议截图内容：

- 底部 `任务 / 商品 / 活动 / 发布 / 我的`
- 已登录后的首页状态

可配说明文字：

> 完成实名后，就可以正式使用小程序。底部导航栏是最常用的功能入口。

## 四、社区任务怎么用

### 1. 在“任务”页查看社区任务

进入底部导航的 `任务` 页，可以看到任务广场。这里可以：

- 查看全部任务
- 查看最新任务
- 查看本楼栋任务
- 按任务地点筛选
- 点击 `详情` 进入任务详情页

【截图06：任务广场】

建议截图内容：

- 顶部筛选区域
- 任务卡片
- `详情` 按钮

可配说明文字：

> 任务页展示的是小区内当前可参与的任务。业主可以按照发布时间、楼栋或任务地点筛选。

### 2. 进入任务详情，查看内容并决定是否参与

在任务详情页，可以看到：

- 任务标题
- 任务金额
- 任务说明
- 图片凭证
- 当前状态
- 操作按钮

根据身份和任务状态不同，常见按钮包括：

- `接受任务`
- `先沟通`
- `与业主聊天`
- `提交完成`
- `确认完成`
- `发起退款`

【截图07：任务详情页】

建议截图内容：

- 任务标题和金额
- 状态
- 页面底部操作按钮

可配说明文字：

> 进入任务详情后，可以先看清楚任务内容，再决定是否接单、沟通或继续后续流程。

### 3. 发布任务

如果自己有需要，也可以点击底部 `发布`，进入发布类型选择页，再选择 `发布任务`。

【截图08：发布类型页】

建议截图内容：

- `请选择发布类型`
- `发布任务`
- `是的,我需要帮忙!`

进入 `发布任务` 页面后，按提示填写：

- 标题
- 说明
- 佣金
- 截止时间
- 楼栋
- 门牌号
- 任务地点
- 可选图片

填写完成后点击 `发布任务`。

【截图09：发布任务页】

建议截图内容：

- 标题 / 说明 / 佣金
- 截止时间
- 楼栋 / 门牌号
- `发布任务`

可配说明文字：

> 发布任务时，建议把内容、时间、地点和报酬写清楚，方便接单人快速判断是否能接。

### 4. 接单后可以聊天、提交完成、等待确认

任务进入进行中后，双方可以通过聊天沟通细节。完成任务的一方可以在页面里上传说明和图片，点击 `提交验收`，发布者确认无误后再点击 `确认完成`。

【截图10：提交验收页】

建议截图内容：

- `完成说明`
- `上传凭证（照片）`
- `提交验收`

可配说明文字：

> 做完任务后，可以上传说明和照片作为完成凭证，方便对方确认，也方便后续留痕。

### 5. 在“我的任务”里查看自己发布和接受的任务

进入 `我的` -> `任务`，可以查看：

- `我发布的`
- `我接受的`

在这里还能进行：

- 查看详情
- 继续付款
- 编辑任务
- 删除记录

【截图11：我的任务页】

建议截图内容：

- `我发布的 / 我接受的`
- 任务列表
- `详情` 或 `查看`

可配说明文字：

> 所有和自己有关的任务，都会集中显示在“我的任务”里，方便统一管理。

## 五、闲置商品怎么用

### 1. 在“商品”页浏览闲置物品

进入底部导航的 `商品` 页，可以看到商品列表。这里可以：

- 按分类筛选
- 浏览商品图片、标题、价格
- 点击商品进入详情

【截图12：商品列表页】

建议截图内容：

- 商品卡片列表
- 分类筛选
- 价格和标题

可配说明文字：

> 商品页展示的是社区内的闲置物品，支持按分类筛选，更方便快速找到需要的东西。

### 2. 商品详情页可以收藏、咨询、购买

进入商品详情页后，可以看到：

- 卖家信息
- 发布时间与位置
- 商品价格
- 商品说明
- 商品图片
- 底部操作按钮

常见按钮包括：

- `收藏`
- `立即购买`
- `聊一聊`
- 如果是自己的商品，还会看到 `编辑商品`

【截图13：商品详情页】

建议截图内容：

- 卖家信息
- 商品价格
- 商品描述
- 底部 `收藏 / 立即购买 / 聊一聊`

可配说明文字：

> 看到感兴趣的商品，可以先收藏，也可以直接联系卖家沟通，再决定是否购买。

### 3. 发布商品

如果自己有闲置物品，也可以点击底部 `发布`，再选择 `发布商品`。

发布商品时可填写：

- 商品图片
- 标题
- 分类
- 价格
- 原价
- 成色
- 交易方式
- 发布楼栋
- 说明

填写完成后点击 `发布商品`。

【截图14：发布商品页】

建议截图内容：

- 图片上传区
- 标题 / 分类 / 价格
- 成色 / 交易方式
- `发布商品`

可配说明文字：

> 发布商品时，建议尽量把图片、价格、成色和说明写清楚，方便别人快速判断是否合适。

### 4. 在“我的商品”里管理自己发布和买到的商品

进入 `我的` -> `商品`，可以切换查看：

- `我发布的`
- `我买到的`

常见操作包括：

- 查看商品
- 咨询会话
- 联系卖家
- 删除记录

【截图15：我的商品页】

建议截图内容：

- `我发布的 / 我买到的`
- 商品列表
- `查看`

可配说明文字：

> 自己发布过的商品、已经买到的商品，都可以在“我的商品”里统一查看和管理。

### 5. 收藏和浏览记录也会自动保存

进入 `我的` -> `收藏`，可以查看：

- 收藏的商品
- 浏览记录

【截图16：收藏 / 浏览记录页】

建议截图内容：

- `收藏 / 浏览记录`
- 商品列表

可配说明文字：

> 看到喜欢的商品，可以先收藏；浏览过的商品，也会自动记录，方便后续再找回来。

## 八、钱包和提现怎么用

### 1. 在“我的钱包”里查看余额和明细

进入 `我的` -> `钱包`，可以查看：

- 可提现余额
- 收支明细
- 提现入口

页面中有 `提现/绑卡` 按钮，点进去即可进入提现页面。

【截图21：我的钱包页】

建议截图内容：

- 可提现余额
- 收支明细
- `提现/绑卡`

可配说明文字：

> 钱包页可以查看自己的收支情况和可提现余额，收入、退款、奖励等都会留在明细里。

### 2. 提现前先绑卡，再提交提现

进入提现页后，页面会分成两步：

- `步骤1：绑定提现银行卡`
- `步骤2：申请提现`

常见操作流程是：

1. 输入银行卡号
2. 选择开户地址（省 / 市）
3. 点击绑定银行卡
4. 输入提现金额
5. 点击确认提现

【截图22：提现页】

建议截图内容：

- `步骤1：绑定提现银行卡`
- `步骤2：申请提现`
- 提现金额输入框
- `确认提现`

可配说明文字：

> 如果后续有任务收入、商品收入或活动奖励，就可以在这里完成绑卡和提现。没有提现需求时，可以暂时不操作这一步。
