## 2) 当前项目采用的风格（现在的实际效果）

- 风格名称（口语版）：多抓鱼 / 日系极简（更“干净、克制”）
- 风格关键词：
  - 背景偏浅灰白，不用大色块铺底
  - 内容用白色“卡片”装起来
  - 圆角更大、阴影更轻（看起来柔和，不“硬”）
  - 尽量少用渐变，按钮以纯色为主
  - 主色用砖红点缀，少量用墨绿做强调

## 6) 统一风格时的简单规则（别复杂）

- 能用 `shadcn.wxss` 里的通用类就别在页面里“写死颜色”
- 渐变能不用就不用（除非你明确想要那种“很活泼”的感觉）
- 按钮尽量用胶囊形（圆角很大），主按钮用砖红 `#B95E49`
- 成功/“生效中”之类提示尽量用墨绿 `#447244`，不要那种很亮的绿
- 卡片用白底 + 轻边框 + 轻阴影，不要厚重阴影

## 额外风格
这种设计风格叫 iOS Segmented 
  Control（分段控制器），是苹果设计语言的经典组件。

  主要特点：
  - 灰色背景容器包裹所有选项
  - 选中项用白色"浮起"的卡片表示
  - 轻微阴影增加层次感
  - 圆角统一，视觉整体

  更广义地说，它属于 Soft UI 或 轻拟态 风格，是扁平化设计（Flat Desi
  gn）和新拟态（Neumorphism）的折中——既保持简洁，又有适度的立体感。

  微信、支付宝、抖音等 App 里的 Tab
  切换、筛选器都大量使用这种样式，用户很熟悉，交互直觉也很清晰。
