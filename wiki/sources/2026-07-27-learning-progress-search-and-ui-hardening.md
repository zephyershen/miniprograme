# 会员学习进度、跨历史搜索与界面一致性加固

## 背景

在会员专栏管理员发布系统建立可回滚暂存基线后，继续处理外部 UI 与功能审计中
可独立验证的项目。管理端基线已固化为 Git 提交 `a3d5c5a`，后续发布候选与无关的
`marketing/` 工作目录保持隔离。

## 已实现

- 全局按钮兼容微信 `style: "v2"` 的最小宽度，统一数字等宽排版和核心灰阶 token，
  扩大资讯互动热区，并清理确认无引用的样式。四个原生 Tab 新增同笔画的深灰/编辑蓝
  线性 PNG 图标。
- 新增共享空态和骨架屏组件，覆盖公开内容、账号、收藏、消息和专栏管理页面；为精选、
  简报、专栏目录和阅读器补齐下拉刷新。页面/组件/专栏样式中的十六进制色值全部归并
  到设计 token，常驻筛选、排序、搜索和管理按钮达到 88rpx 点按高度。
- 会员专栏阅读器在图片临时签名失效时自动强制换签一次；仍失败才显示人工重试，
  避免无限重试。
- 新增 `knowledge_column_progress` 私有集合。服务端重新校验 Pro 权益和当前已发布
  内容后保存阅读进度；客户端显示总进度、单课进度和“继续学习”，草稿预览不记录。
- 新增一框全站关键词搜索。页面不再要求先选范围；服务端内部聚合官方动态、资讯、
  推文、完整 GitHub 开源库、会员专栏和知识简报，并以分来源复合游标稳定分页，
  避免近期 GitHub 条目与资讯范围重复。服务端按免费 24 小时、Pro 30 天、管理员
  全归档边界搜索资讯，GitHub 使用完整公开库；免费用户
  只能搜索专栏公开目录字段，Pro 才会匹配受保护正文，简报搜索要求 Pro。搜索页增加
  本地历史、关键词高亮、分享和跨内容正确跳转；查询 token 受 1024 字节索引字段
  限制保护，公开结果不会返回内部 token。
- 新增 `searchTokenBackfill`。独立定时器自动推进有界批次，维护令牌 action
  保留为人工恢复入口；它按同步状态中的服务端游标扫描旧条目，单条事务只写 token
  版本、token 和更新时间。搜索索引字段不属于内容/视觉 `contentHash`，因此回填不会
  令在途截图任务失效。中断可续跑、重复执行幂等，并用游标比较阻止并发旧批次越过
  新进度。稳定失败的单条文档连续五次失败后进入有界隔离列表，主游标继续前进，
  独立定时器持续重试；批量故障不会被误当作毒丸。`knowledgeOps.status` 暴露扫描量、
  安全错误码、隔离 ID 和批次耗时。首页搜索入口保持常驻，主扫描完成前由搜索页
  在实际查询时展示“搜索正在准备”；`feedSearch` 返回 `SEARCH_UNAVAILABLE`，
  避免把缺结果伪装成“没有找到”。
- 精选、搜索和会员价格中的普通说明文字不再误用表单 `<label>`；会员目录为免费用户
  展示“Pro 自动记录学习进度”的真实转化说明；管理列表新增本地关键词和发布状态筛选，
  有筛选时禁用容易误排的上下移动。
- 2026-07-28 根据开发者工具实画面修正首页控制条回归：搜索入口不再受
  `feed.searchReady` 条件隐藏；筛选、排序和搜索仍保留 88rpx 点击范围，但视觉胶囊
  缩回 60rpx，避免把无障碍热区直接画成过高组件。
- 资讯列表、详情和资讯类搜索结果增加明确标注的 `推荐热度 100–1000`。数值由稳定
  内容标识确定，同一条资讯跨页面和刷新保持不变；它不写入或覆盖
  `engagement.likeCount`，心形按钮继续只显示真实喜欢数。

## 合同与验证

- 本地数据库合同为 29 个 `ADMINONLY` 集合；本地增量索引合同为 50 个索引。
- `knowledge_feed_items` 的搜索索引仍低于单集合保守索引数量边界。
- `npm.cmd run check` 通过：38 个 JSON、354 个 JavaScript、16 个注册页面，
  客户端包约 0.70 MiB。
- `npm.cmd run verify` 通过：767/767 Node 测试，以及环境合同、数据库合同、索引
  合同、覆盖率和生产依赖审计均成功。
- 微信开发者工具 CLI `auto` 与 `open` 成功；自动化实画面确认搜索范围卡为 0，
  列表和详情显示相同推荐热度，真实互动栏仍为“评论 / 喜欢 / 收藏 / 分享”。

## 发布边界

- 本轮没有创建或修改生产集合、索引和数据，没有部署云函数，也没有上传或提交
  微信小程序版本。
- 生产仍维持此前回读的 28 个合同集合和 47 个合同索引。本地新增的进度集合与三个
  搜索/进度索引必须在后续发布流程中按“集合与规则 → 索引 → 云函数 → 小程序”
  顺序应用。必须从同一已提交 SHA 部署并回读 `knowledgeFeed` 与 `knowledgeOps`；
  云函数部署后独立回填定时器会自动推进；上传小程序前用
  `knowledgeOps.status.searchBackfill` 确认 `ready=true`、完成时间和隔离状态，
  必要时再用维护 action 加速，并完成免费/Pro/管理员搜索 canary。
- 当前 `SEARCH_TOKEN_VERSION` 使用精确完成版本门禁。未来变更分词算法时不得直接
  覆盖同一 token 字段；应先增加并回填并行的 vNext 字段与索引，完成后原子切换查询
  与 readiness，再在稳定观察期后移除旧字段和索引，避免版本切换期间停搜。
- 微信订阅消息未用假模板实现。实际接入仍需公众平台创建的真实模板 ID、每个模板
  的关键词字段名及用途映射；配置完成前不显示授权入口，也不保存不可用的订阅记录。
- 深色模式不是补一个 `darkmode` 字段即可安全完成；现有插图、原生导航、遮罩和语义
  色尚无完整深色合同，因此作为独立视觉验收版本保留，不属于本次发布阻塞项。
