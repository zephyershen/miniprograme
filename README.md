# 别收藏了 · 知识更新台

面向微信端的编辑型知识获取平台。首页用横向频道和资讯卡片组织 AI/科技动态，并提供来自 AIGCLINK 的 GitHub 开源库；支持喜爱、收藏、会员评论和微信分享。

## 本地开发

1. 在微信开发者工具导入仓库根目录。
2. AppID 使用 `wxcb0f641838abf6e6`，云环境使用 `hyyc-1gi3f5sqc5becabf`。
3. 分别在 `hyyc/cloudfunctions/knowledgeFeed`、`knowledgeOps`、`membershipBilling`、`hyyc/cloudrun/source-preview-renderer` 及其 `docker` 子包使用锁文件安装依赖。
4. 先按 `docs/cloud-cleanup.md` 核对云端资源，再通过根目录 `cloudbaserc.json` 部署四个生产函数；`knowledgeOps` 必须配置至少 32 位的云端维护令牌，会员支付按 `docs/wechat-virtual-payment-membership.md` 配置。
5. 在 `hyyc` 目录执行 `npm run verify`，统一运行静态检查、环境合同、全量测试、覆盖率门槛和生产依赖审计。
6. 开发版、体验版和正式版都可以发起已登记的真实写请求，用于上线前完整联调；它们当前连接同一生产云环境，测试点赞、收藏、评论、资料、媒体和支付时会产生真实数据，所有请求仍须通过服务端身份、内容审核、对象所有权和支付配置校验。

## 模块边界

- `hyyc/pages/` 只负责微信页面生命周期、用户事件和 `setData` 编排，不承载可复用业务规则。
- `hyyc/features/knowledge-feed/` 集中资讯频道、筛选、排序、列表/详情展示模型和资讯 API；新增首页能力优先放在这里。
- `hyyc/features/engagement/` 统一封装喜爱、收藏、评论的 API、展示模型和页面间状态同步；会员权限由云端服务裁决。
- `hyyc/features/membership/`、`billing/`、`curated-feed/`、`ai-column/`、`briefing/` 分别拥有会员会话、支付、精选、专栏和简报的 API 或展示模型；页面不能自行推断付费权限。
- `hyyc/services/cloud-functions.js` 是小程序端统一云函数传输层，业务模块不直接重复处理 CloudBase 响应和错误。
- 小程序运行时代码的相对 `require` 必须显式写出 `.js` 扩展名，页面不得通过 `...require(...)` 聚合导出；`npm run check` 会阻止这两类微信打包器不兼容写法。
- `hyyc/cloudfunctions/knowledgeFeed/adapters/` 隔离外部资讯源，`repositories/` 隔离数据库，`services/` 编排指纹同步、权限、查询、迁移、封面和原文截图用例，`policies/` 定义定时入口及维护鉴权，`presenters/` 定义对小程序公开的数据字段。
- `hyyc/cloudfunctions/knowledgeOps/` 是服务端运维入口，只负责人工会员/管理员授权、分析回填和状态查询；小程序公共 action 不包含维护操作。
- `hyyc/cloudfunctions/membershipBilling/` 隔离微信小程序虚拟支付的登录换取、签名、官方查单、发货确认、退款核对和会员发放；客户端支付回调不能直接授予权益。
- `hyyc/cloudrun/source-preview-renderer/` 是独立 Playwright 截图服务；生产必须通过回环代理和私网出口阻断运行，部署契约见该目录 README。
- 接入新资讯源时新增 adapter 并保持统一条目结构，避免把供应商字段、请求方式或品牌判断写进页面、查询服务和数据库仓储。

## 当前产品边界

- 待消化队列最多 5 条，结论卡最多 20 张。
- 只支持无需登录的中英文 HTTPS 文章页。
- 不保存网页全文，不提供推送、实名、定位或聊天功能；昵称、头像、评论文本与评论图片在公开前都必须通过内容检查。
- 当前聚合资讯源提供近 7 天 AI 前沿和科技全量资讯，页面只显示原发布方和原文链接，不暴露聚合服务实现。
- 原文封面可用时缓存到 CloudBase；缺少真实图片的条目使用受控原文页面截图，不生成与原文无关的 AI 配图，也不保留空白图片框。
- 单一定时器每分钟检查上游指纹，变化时立即拉取全量条目；指纹不变时每 6 小时做一次 ETag 条件校验，每 24 小时做完整一致性刷新。视觉任务在每分钟第 10、25、40、55 秒尝试启动，每个编排周期最多 6 个隔离截图并发并受全局/任务租约、防重与软截止时间共同限制。最新任务获得加权机会后仍会给修复与重试任务保留时隙。失败指数退避，终态和孤儿图片都有回收路径。用户读取不会串行触发截图。
- 无图资讯也会进入首页和详情，不因视觉素材缺失而隐藏。真实封面优先；全部缺图条目都会进入 `knowledge_feed_visual_jobs`，没有封面时由公网服务生成原文截图，截图是增强内容，不是公开门槛。
- 首页和相关阅读优先使用独立的 360×253 轻量 JPEG 缩略图并懒加载，详情仍使用完整封面和全部原文截图；已有原图只派生缩略图，新视觉在原图与缩略图都成功后原子发布，迁移期间列表自动回退原图。
- 首页筛选使用服务端计数矩阵，触底分页只通过数据路径追加新行。详情页用原文截图自动/手动轮播、圆点和整组全屏预览组织内容；页面只挂载当前与相邻图片并在自动播放一轮后停止，长页连续截图安全上限为 12 张。
- 上游动态接口只提供最近 7 天；后台把 `mode=all` 条目逐条入库，并用日报精选回填既有历史。普通用户由服务端限制近 24 小时，人工 Pro 为 30 天，管理员可查看全部已归档数据；管理员授权与会员状态独立。GitHub 开源库不按资讯日期折叠或限时，只使用 AIGCLINK 原生标签筛选。
- 首页支持按时间、公司与模型、技术方向组合筛选，并显示当前匹配的全部资讯数量；“最新”将包括放大主稿在内的全部资讯按发布时间从新到旧排列，“热度”将全部资讯按热度从高到低排列。
- 首页首屏只请求并渲染 8 条列表 DTO，用户触底后通过稳定游标追加 8 条；统计和筛选矩阵只在首屏返回，频道或筛选变化时从第一页重新加载。
- 小程序使用资讯、专栏、简报、我的四个原生 Tab；资讯顶部带锁“精选”进入独立会员页，不参与普通频道过滤。免费精选/简报只展示明确标注的体验示例，专栏只展示学习路径预览；付费专栏海报不进入客户端包，只在服务端校验会员后下发。真实精选和简报由已接入的分析任务生成；新购入口默认关闭，只有真机支付/退款矩阵完成后同时开启服务端 `WECHAT_VIRTUAL_PAY_RELEASE_APPROVED` 和产品购买能力才会开放。
- 当前真实管理员账号可在“我的”页切换普通用户、Pro 会员和管理员三种服务端身份预览，开发版和体验版同样可用；切换状态保存在管理员授权记录中，普通用户无法调用，也不会创建真实付费会员记录。
- 详情页在“接着看”之前展示来源名称和可展开的完整 URL，右侧提供紧凑复制按钮。原始出处只对已在微信公众平台验证的业务域名在小程序 `web-view` 内打开；其他来源点击后复制链接，提示用户到手机浏览器粘贴访问。
- 娱乐、社会、游戏、英语及 OpenAI、Grok、GLM、DeepSeek 等厂商官方直连仍未接入，不能把当前首页描述为全频道实时新闻服务。
- AI 月度用量由应用侧按 Token 估算，超过 10 元后停止新增处理。
- 10 元硬上限只计算模型 Token，不包含 CloudBase 套餐、云函数和外网流量费用。

更完整的部署、云资源和验证说明见 `docs/` 与 `wiki/`。
